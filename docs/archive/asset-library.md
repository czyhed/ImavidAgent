## 0. 结论先行

1. **素材库分两个页签：`素材` 与 `预制模板`。**「素材」展示服务端真实保存的产出；「预制模板」提供可直接带入生图的提示词和示例图。
2. **真实产出只有一个事实来源：服务端任务与对象存储。** 所有已成功的生成/改图结果都进入素材库，按时间分页读取，不沿用生图页「最近 50 条」的上限，也不依赖浏览器本地记录。
3. **预制模板是「提示词 + 示例图」，不是可编辑的 PSD 或分层设计文件。** 点击模板只把提示词和建议参数带入生图页，必须由用户再次确认计费，不自动提交、不自动扣费。
4. **当前真实产出只有 2 张成功图片。** 六步流程里的 A01–A05、V01 是页面内 SVG 模拟；商品主图只存在当前浏览器 `localStorage`；视频执行器尚未接入。它们不应被包装成真实素材。**已确认：本期只收真实产出**，演示内容和本机商品图不进入素材库，也不计入统计。
5. **已确认 P0 为只读浏览**：真实产出全量分页、搜索筛选、详情、下载、复制提示词、用作改图源；预制模板浏览与带入生图。收藏、标签、隐藏/恢复、批量 ZIP、永久删除放到 P1，避免第一期同时做完整的数字资产管理。
6. **已确认示例图使用项目自制示意图**：零成本、明确标注「示例」，不调用 OMYAI 付费生成；后续可替换为真实样图。

## 1. 用户目标与范围

### 1.1 用户明确希望

- 所有之前生产的内容，都能在素材界面看到，而不是散落在生图记录或项目流程里。
- 素材界面同时提供预制提示词模板、图片等，降低第一次使用的门槛。

### 1.2 本期范围（P0 已确认）

| 优先级 | 范围 | 说明 |
| --- | --- | --- |
| P0 | 真实产出全量列表 | 服务端分页，覆盖历史与后续所有成功图片；失败/待核实任务不算产出 |
| P0 | 搜索、筛选、详情、下载、复制提示词 | 详情可追溯到原任务、模型、尺寸、质量、改图源 |
| P0 | 用作改图源 | 仅限同一供应商、支持改图且未超过供应商 24 小时有效期的成功任务 |
| P0 | 预制模板浏览与带入生图 | 分类、搜索、详情、占位符填写、带入提示词和推荐参数；不自动提交 |
| P0 | 真实与演示分离 | 不把模拟项目资产、浏览器本地商品图混入真实统计 |
| P1 | 收藏、标签、隐藏/恢复、批量下载 ZIP | 管理能力；隐藏需服务端持久化，并与生图页一致 |
| P1 | 商品/项目关联、按 SKU 筛选 | 依赖商品与项目真实持久化，不在本期伪造 |
| P1 | 视频产出、上传素材 | 依赖视频执行器与任意参考图上传 |
| 不做 | 模板市场、模板后台编辑、分层排版、自动打标、完整 DAM | 不扩大为通用素材管理系统 |

### 1.3 不承诺

- 不承诺旧素材都能继续「改图」：供应商只保留 24 小时可编辑源图，MinIO 长期保存的是结果图，不是可编辑源。
- 不承诺模板图片能直接作为生成参考图：任意参考图上传尚未接入，预制图片只用于浏览、下载和风格参考。
- 本文把「预制图片」理解为模板的示例图/灵感图，不是可直接合成到成品里的底图、背景或道具素材。若需要后者，属于图片合成与素材上传能力，需另立范围。
- 不承诺模板能自动填入商品事实：商品资料尚未服务端化，模板只提供占位符，由用户填写或后续从商品档案带入。
- 不把「素材库里有图」等同于「已审核、已授权、可商用」；授权与审核状态后续由 F19/F22 补齐。

## 3. 信息架构与页面

### 3.1 入口与结构

保留现有应用外壳（左侧导航、顶部栏、页面头部），新增素材页：

```text
素材库 / ASSET LIBRARY                          [去生图]
所有产出，都在这里。
共 2 件 · 本月 +2 · 占用 3.2 MB

[ 素材 2 ] [ 预制模板 10 ]

搜索提示词、模板或标签…            [类型 ▾] [来源 ▾] [时间 ▾] [仅收藏]

┌────────┬────────┬────────┬────────┐
│ 图片   │ 图片   │ 模板   │ 模板   │   卡片网格
│ 缩略图 │ 缩略图 │ 示例图 │ 示例图 │
│ 提示词 │ 提示词 │ 模板名 │ 模板名 │
│ 模型/尺寸/时间                  │
└────────┴────────┴────────┴────────┘
```

- 左侧导航「素材」进入本页；顶部标题「素材库」，说明「真实产出 · 预制模板」。
- 页签「素材」和「预制模板」共用搜索框，但筛选条件各自独立；切换页签不丢搜索词。
- 页面内部不新增二级导航，避免和六步流程的左侧步骤栏混淆。
- 当前应用没有 URL 路由，素材页状态只保存在页面内存；刷新回到默认列表，可接受。

### 3.2 「素材」页签

**筛选**

- 类型：全部 / 图片 / 视频（视频本期为空，显示“视频执行器未接入”）。
- 来源：全部 / 生图 / 改图 / 项目 / 上传（P0 实际只有生图与改图；项目/上传置灰并说明）。
- 时间：全部 / 近 7 天 / 近 30 天 / 本月。
- 排序：最新优先（P0 固定），不提供任意排序。
- 搜索：提示词、标题、标签；不搜索模型密钥、渠道 Base URL 等配置。
- 计数：每个筛选项显示数量；总数以服务端返回为准，不在前端自行累加。

**卡片**

- 缩略图，保持原始宽高比或用统一 1:1 裁切（建议统一裁切，详情看原图）。
- 左上角类型/来源角标：`生图` / `改图`；右上角收藏按钮（P1）。
- 提示词摘要最多两行；下方一行元信息：模型简称 · 尺寸 · 相对时间。
- 状态角标只在详情出现；列表默认只展示已成功产出。
- 悬停显示「预览」「下载」「用作改图源」；移动端改为卡片底部按钮，避免依赖 hover。
- 图片加载失败显示占位和「文件不可用」，记录仍保留，不能静默消失。

**详情抽屉（右侧，桌面约 420px；移动端全屏 sheet）**

- 大图预览，支持点击查看原图。
- 元信息：创建时间、模型、尺寸、质量、操作（生图/改图）、来源任务编号、文件大小。
- 完整提示词，带「复制提示词」。
- 改图关系：若来自改图，显示「源图」并可跳转到源素材；形成可追溯的版本链。
- 操作：
  - 下载原图。
  - 复制提示词。
  - 用作改图源（满足条件时可用）。
  - 收藏 / 隐藏（P1）。
- 「用作改图源」的禁用原因必须写清楚：渠道不支持改图、源图超过 23 小时、供应商不是同一家、没有可用的改图模型。
- 旧素材仍可浏览、下载、复制提示词；只是不能直接改图。

### 3.3 「预制模板」页签

- 顶部说明：「预制提示词与示例图，不计入产出。带入生图后仍需确认费用。」
- 分类：全部 / 白底 / 场景 / 卖点 / 促销 / 改图 / 视频分镜。
- 卡片：示例图、模板名、一句话用途、推荐画幅、标签、`预制` 角标。
- 详情抽屉：
  - 示例图（标注“示例，不是你的产出”）。
  - 模板说明、适用商品类型、推荐画幅与质量。
  - 占位符表单：商品名称、品类、核心卖点、品牌名等；必填项未填时按钮禁用。
  - 完整提示词预览，随占位符输入实时更新。
  - 「带入生图」：填入提示词、选择模型、尽量匹配推荐画幅/质量；不勾选计费确认、不提交。
  - 「复制提示词」：复制当前填充后的文本。
  - 版权/来源说明：项目自制、授权素材或供应商生成，写明可商用范围。
- 示例图只用于浏览与下载；不把静态图片 URL 发给供应商，不伪装成可上传参考图。
- 视频分镜模板只提供提示词与分镜结构说明；视频执行未接入，按钮显示「视频尚未接入」，不生成假视频。

## 4. 真实产出收录规则

### 4.1 收录

- 收录条件：任务状态 `succeeded` 且 MinIO 对象存在。
- 每次成功生成或改图 = 一个独立素材；改图不覆盖原图。
- 失败、待核实、排队中、转存中都不是素材；它们的记录继续留在生图/任务侧，避免用户误以为已有成品。
- 同一任务重复回调、页面重复刷新不得产生重复素材；以 `(source, source_id)` 唯一约束保证幂等。
- 历史任务必须回填；不能只从上线之后开始记录。
- 素材删除（P1）不影响任务与计费记录；任务记录用于对账，不因图片删除而消失。

### 4.2 与生图页的一致性

- 生图页「生成记录」继续服务当前创作；素材库是完整档案。
- 生图页的「移除」当前只影响本页面临时视图，刷新后恢复。P0 只读，不改这个行为，但必须在界面说明「移除只影响当前视图，服务端与素材库仍保留」。
- P1 建议改为服务端 `hidden_at`，素材库与生图页共同遵守；素材库提供「显示已隐藏」开关，保证“所有内容仍可找回”，而不是被静默删除。同时把生图页按钮文案改为「在素材库隐藏」，避免用户以为文件已删除。
- 素材库的「用作改图源」复用生图页已有的源图校验，不另写一套规则。

### 4.3 统计口径

- 总数：未删除、未隐藏的成功素材数；打开「显示已隐藏」时单独标注。
- 本月新增：按 `Asia/Shanghai` 时区统计 `created_at`。
- 占用空间：服务端 `bytes` 求和；仅作参考，不是账单。
- 模板数量单独统计，不计入素材总数、占用空间和本月产出。
- 失败任务不计入产出；重试后成功只算最终成功的一张，不重复计数。

## 5. 预制模板设计

### 5.1 首版建议模板

首版建议 10 个，先覆盖最常用的白底、场景、卖点和改图；数量可再裁剪。

| 分类 | 模板 | 用途 | 建议画幅 | 备注 |
| --- | --- | --- | --- | --- |
| 白底 | 白底主图 · 干净台面 | 平台主图，主体完整、自然阴影 | 1:1 | 不改变结构、颜色、数量 |
| 白底 | 白底主图 · 柔和投影 | 更柔和的家居质感 | 1:1 | 避免过度反光 |
| 场景 | 场景图 · 晨光客厅 | 家居日用氛围 | 1:1 / 4:5 | 场景不遮挡主体 |
| 场景 | 场景图 · 收纳使用中 | 展示使用状态 | 4:5 | 不虚构商品没有的功能 |
| 卖点 | 卖点图 · 大字号利益点 | 一句核心卖点 + 商品 | 1:1 | 文字宜少，避免乱码 |
| 卖点 | 卖点图 · 参数三宫格 | 容量/尺寸/材质 | 1:1 | 只使用已确认参数 |
| 促销 | 促销图 · 节日氛围 | 活动主视觉 | 1:1 | 不写未经确认的价格/折扣 |
| 改图 | 只换背景 · 保留商品 | 基于成功图换场景 | 原图比例 | 需要 24 小时内可改图源 |
| 改图 | 去除杂物 · 保留主体 | 清理画面干扰 | 原图比例 | 不改变商品细节 |
| 视频分镜 | 15 秒商品短片 · 开场/细节/收尾 | 分镜提示词与镜头顺序 | 9:16 | 视频执行未接入，仅提示词 |

### 5.2 模板字段

```json
{
  "id": "tpl-white-clean-01",
  "version": 1,
  "name": "白底主图 · 干净台面",
  "category": "white",
  "kind": "image",
  "description": "适合平台主图的干净白底，保留商品结构与颜色。",
  "prompt": "将{{product}}置于纯白台面中央，柔和自然光，真实接触阴影，{{angle}}视角，主体完整，不改变结构、颜色和数量，无文字，无道具。",
  "placeholders": [
    { "key": "product", "label": "商品名称", "required": true, "example": "白色收纳盒" },
    { "key": "angle", "label": "视角", "required": false, "example": "正面微俯" }
  ],
  "suggested": { "ratio": "1:1", "quality": "high" },
  "tags": ["白底", "主图"],
  "preview": "tpl-white-clean-01.webp",
  "license": "项目自制示意图，仅用于界面演示",
  "updatedAt": "2026-10-20"
}
```

规则：

- `id` 稳定，不重复使用；改提示词必须升 `version`，旧版本保留在配置历史中。
- 占位符必须在 `prompt` 中出现；必填项为空时禁止带入。
- 模板只是提示词，不包含供应商密钥、Base URL、模型内部参数。
- 推荐尺寸不一定被当前模型支持：带入时按画幅挑选当前模型支持的尺寸；没有匹配画幅时选最接近项并提示，不强行提交。
- 模板不能写入未经确认的价格、折扣、材质、认证或绝对化用语；提示词中应明确“只使用已确认信息”。
- 中文提示词可能产生画面文字；卖点图应提示“文字可能不可控，必要时后期处理”，不承诺文字零错误。

### 5.3 预制图片

- 每个模板至少 1 张示例图，建议 3:4 或 1:1，宽 800–1200px，WebP/AVIF，单张控制在 150 KB 内。
- 示例图必须明确标注「示例」，卡片和详情都不能让它看起来像用户产出。
- **已确认来源：项目自制示意图/抽象封面（零成本）。** 不冒充真实商品图，适合原型评审；每张标注「示意图 · 非真实生成」，不调用 OMYAI，不产生费用。后续如需更真实的样图，再单独确认是否用 OMYAI 生成或采用用户授权图片。
- 示例图放 `prototype/presets/`，由服务端按模板配置白名单提供；不放入 MinIO 私有桶也能工作。后续如需运营后台管理，再迁移到对象存储与模板表。
- 不把示例图当作可上传参考图；不把私有 MinIO URL 或本地路径发给供应商。

### 5.4 带入生图的交互

1. 用户打开模板详情，填写占位符。
2. 点击「带入生图」，跳转到生图页，填入提示词、选择模型、匹配画幅/质量。
3. 显示来源提示「来自模板：白底主图 · 干净台面」。
4. 计费确认保持未勾选；用户必须自己确认后提交。
5. 若生图页有未确认的上次提交，先提示并保留原请求，不用模板覆盖；用户明确放弃后再带入。
6. 带入不创建任务、不调供应商、不产生费用。

## 6. 数据模型与接口

### 6.1 素材索引表

建议新增 `sj_assets` 作为素材库索引，不直接改任务表的语义。任务是执行与计费记录，素材是展示与复用记录；两者通过 `source_id` 关联，素材保存必要快照，避免历史展示随任务表变化。

```sql
CREATE TABLE IF NOT EXISTS sj_assets (
  id uuid PRIMARY KEY,
  workspace_id text NOT NULL DEFAULT 'local',
  source text NOT NULL,              -- generation | upload | project
  source_id text NOT NULL,           -- 生图任务 UUID；其他来源的稳定 ID
  kind text NOT NULL,                -- image | video
  status text NOT NULL DEFAULT 'ready',
  object_key text NOT NULL,
  content_type text NOT NULL,
  bytes bigint NOT NULL,
  thumb_key text,
  prompt text,
  model_id text,
  provider_id text,
  size text,
  quality text,
  operation text,                    -- generate | edit
  source_asset_id uuid,
  title text,
  tags text[] NOT NULL DEFAULT '{}',
  favorite boolean NOT NULL DEFAULT false,
  hidden_at timestamptz,
  deleted_at timestamptz,
  created_at timestamptz NOT NULL DEFAULT now(),
  updated_at timestamptz NOT NULL DEFAULT now(),
  UNIQUE (source, source_id)
);

CREATE INDEX IF NOT EXISTS sj_assets_list
ON sj_assets (deleted_at, hidden_at, created_at DESC, id DESC);
```

说明：

- 生图素材的 `id` 可直接使用任务 UUID，减少映射；但唯一性仍由 `(source, source_id)` 保证。
- `source_asset_id` 指向改图源素材，用于版本链；不设置强外键，避免删除素材时破坏历史。
- `workspace_id` 现在固定 `local`，为后续 F01 数据隔离预留；当前接口仍只允许本机访问。
- `tags`、`favorite`、`hidden_at` 可以先建表不开放 UI；P1 再使用。
- 视频、项目产出、上传素材复用同一张表，`kind`/`source` 区分；视频执行器未接入前不写入假数据。

### 6.2 历史回填

上线时执行一次性幂等回填，覆盖所有成功任务，不只最近 50 条：

```sql
INSERT INTO sj_assets (
  id, workspace_id, source, source_id, kind, status,
  object_key, content_type, bytes, prompt, model_id, size, quality,
  operation, source_asset_id, created_at
)
SELECT
  id, 'local', 'generation', id::text, 'image', 'ready',
  output->>'key', output->>'contentType', (output->>'bytes')::bigint,
  input->>'prompt', input->>'modelId', input->>'size', input->>'quality',
  input->>'operation',
  CASE WHEN input->>'sourceJobId' IS NOT NULL
       THEN (input->>'sourceJobId')::uuid END,
  created_at
FROM sj_generation_jobs
WHERE status = 'succeeded' AND output IS NOT NULL
ON CONFLICT (source, source_id) DO NOTHING;
```

- 每次服务启动可再跑一次回填，修复“图片已转存但索引写入失败”的情况。
- 索引写入失败不能让已经成功的生成任务变成失败；记录错误并在下次启动修复。
- 回填不调用供应商、不重复计费。

### 6.3 接口建议

| 方法 | 路径 | 行为 |
| --- | --- | --- |
| GET | `/api/assets?cursor=&limit=24&kind=&source=&q=&favorite=&hidden=` | 分页返回素材，按 `created_at DESC, id DESC`；`limit` 上限 60 |
| GET | `/api/assets/:id` | 单条详情，含源图关系、可用改图模型判断所需字段 |
| GET | `/api/assets/:id/file` | 原图 inline；`?download=1` 为附件；文件名用 UUID，不用用户输入 |
| GET | `/api/assets/:id/thumb` | 缩略图；缺缩略图时按需生成并缓存，失败则回退原图 |
| PATCH | `/api/assets/:id` | P1：收藏、隐藏/恢复、标题、标签；需要 CSRF |
| DELETE | `/api/assets/:id` | P1：软删除记录并处理对象；需要明确二次确认与审计 |
| GET | `/api/asset-templates?category=&q=` | 返回内置模板与示例图 URL；公开配置，不含密钥 |
| GET | `/presets/<file>` | 按模板配置白名单提供示例图，不允许目录遍历 |

实现约束：

- 所有图片只经同源接口返回，浏览器不接触 MinIO 端点、密钥或签名 URL。
- 列表接口不返回完整提示词的大字段？P0 可以返回摘要 + 详情再取全文，避免一页 24 条长提示词；详情接口返回全文。
- `q` 需要转义 `%`、`_`，使用参数化查询；中文子串匹配先 `ILIKE`，规模变大再评估 `pg_trgm`。
- 游标使用 `(created_at, id)`，不使用页码，避免新增素材导致翻页重复/遗漏。
- `hidden` 默认 0；`hidden=1` 只返回已隐藏，需 UI 明确开关。
- 错误统一返回现有 `AppError` 结构，前端显示可读原因；不泄露 SQL、对象键或连接信息。

### 6.4 缩略图

- 新任务成功转存后生成缩略图，建议最长边 640px、WebP 质量 75，存 `generation/<id>/thumb.webp`。
- 历史素材首次请求缩略图时生成并缓存；生成失败回退原图，不阻断浏览。
- 需要新增图片处理依赖（建议 `sharp`）。若暂不引入依赖，P0 可先对原图做 `loading="lazy"` 和每页 24 条，但“所有历史”增长后会明显变慢，缩略图仍应尽快补上。
- 缩略图不是新的计费任务，不调用供应商。

### 6.5 可选：模板来源追踪

若希望统计“哪些产出来自模板”，可在任务输入中增加可选 `templateId`、`templateVersion` 字段并写入 `input`。该字段只作展示与统计，不参与计费、不决定模型；没有该字段的历史任务照常显示。P0 可不做，模板带入的提示词本身已足够使用。

## 7. 安全、性能与边界

- **权限**：当前仅本机单用户；接口继续校验 Host、Origin、CSRF。未来多用户时必须按 `workspace_id` 过滤，不能只靠前端隐藏。
- **密钥**：素材接口不返回渠道密钥、Base URL 或供应商内部 ID；提示词可能含商品信息，不写日志、不导出到第三方。
- **文件**：对象键只来自数据库；下载文件名由 UUID 生成；校验 `Content-Type`；不支持 SVG 上传（避免脚本），示例图 SVG 仅作为项目静态资源时要谨慎。
- **性能**：分页 + 缩略图 + 懒加载；列表接口做轻量字段；详情再取全文。不要在首屏请求全部原图。
- **完整性**：MinIO 对象缺失时标记「文件不可用」，保留记录并允许后续修复；不能把缺失当成成功。
- **删除**：P1 的永久删除必须说明“任务与计费记录保留、图片文件删除、不可恢复”；隐藏与删除分开。
- **演示数据**：演示产出不写数据库，不计入统计；如要展示，使用独立「演示」开关和角标，默认关闭。
- **商用**：模板示例图的授权、生成标识、平台主图规则仍需 F22/F19 补齐；素材库只提供来源与提示词追溯，不自动判定可商用。

## 8. 验收清单（P0）

1. 打开左侧「素材」能看到真实素材页，不再是无效按钮；未连接服务端时有明确提示，不显示假真实数据。
2. 数据库中存在 2 条以上成功任务时，素材库显示全部成功结果；超过 50 条时仍能通过分页看到更早记录，数量与数据库一致。
3. 失败/待核实任务不出现在「素材」默认列表，也不会被误算为产出；相关任务仍可在生图侧查询。
4. 搜索提示词、按类型/来源/时间筛选结果正确；清空条件恢复完整列表；无结果有空状态。
5. 详情展示的提示词、模型、尺寸、质量、操作、时间、文件大小与原任务一致；改图素材能跳转到源图。
6. 下载得到可打开的原图；复制提示词与详情文本完全一致；文件缺失时有明确提示。
7. 24 小时内、同供应商、支持改图的素材可以带入生图并选中为改图源；其他素材按钮禁用且说明原因；带入不自动提交、不扣费。
8. 「预制模板」至少展示首版模板，分类与搜索可用；示例图有「示例」标识，不计入素材数量。
9. 填写必填占位符后「带入生图」能填入提示词并匹配当前模型支持的尺寸/质量；计费确认未勾选；不创建任务。
10. 未填必填占位符、当前模型不支持推荐画幅、存在未确认的上次提交时，都有明确拦截提示，不覆盖原请求。
11. 移动端无横向溢出；卡片、抽屉、按钮可用键盘操作；图片有可读的替代文本。
12. 接口不返回 MinIO 密钥、渠道密钥或供应商临时 URL；浏览器只请求同源 `/api/assets/*` 与 `/presets/*`。
13. 回填/重复回调/刷新不会产生重复素材；删除或隐藏（P1）后统计同步更新。
14. 自动化测试覆盖：分页边界、搜索转义、未授权访问、对象缺失、改图源过期、模板占位符校验；浏览器测试不提交付费任务。

## 9. 实施顺序建议

1. **数据与回填**：`sj_assets` 表、启动回填、成功后索引写入；先用现有 2 张图验证。
2. **只读素材页**：分页列表、搜索筛选、详情抽屉、原图下载、复制提示词；接真实接口。
3. **预制模板**：`config/asset-templates.json`、示例图静态白名单、模板页签、占位符与带入生图。
4. **改图源联动**：素材详情「用作改图源」接到生图页；校验同供应商、改图能力、23 小时限制。
5. **缩略图**：新任务生成 + 历史按需生成；压测 100+ 条列表。
6. **P1**：服务端隐藏/恢复与生图页统一、收藏、标签、批量 ZIP、永久删除。
7. **测试与文档**：接口测试、浏览器测试、README/PHASE1 状态同步；明确未实现项。

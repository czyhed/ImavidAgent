## 实施顺序与验收门槛

1. **本轮已实现：** 生命周期统一投影、成功输出登记 draft、工作流实例编辑与冲突恢复、代表项目 / 商品直达、对象 URL 同步与刷新恢复。验证范围见文末。
2. **下一优先：交付数据语义。** 每个并行输出保存独立生成版本；方案 v2 明确旧产物、候选、审核和导出的继承或复用记录，并在同一事务锁定方案。验收：v1 仍可读；v2 未修改项不重复计费；导出区分沿用与新生成；并发追加只产生一个版本；重复请求幂等。完成前不开放追加方案按钮。
3. **核心输入与恢复。** 商品原图通过 sourceAssetId 预检后显式传入项目工作流，素材可明确作为源图带入；完善失败 / unknown 原任务核实和免费输出登记恢复。验收：缺原图或资料冲突时阻止相关生成；恢复不自动提交新的付费请求。
4. **真实输出。** 接入获授权的模板渲染器，检查字体、文字溢出与画幅；各分支独立候选、审核和导出。Q-08 字体 / 模板授权未确认前不冒充渲染成功。
5. **运营与辅助入口。** 复用 DeepSeek 网关补齐 03/04/05 结构化辅助、AI 查价采用与人工账本复核；待办进一步定位到具体任务 / 渠道记录。
6. **条件项。** Q-02 视觉供应商与费用 / 上传协议，Q-04 1688 真实样本，Q-08 字体 / 模板授权，Q-10 查价来源 / 时效 / 费用。确认前保留未接入状态。视频执行、任意参考图与批量生产按后续范围处理。

功能完成须逐编号验收，不以测试数量、菜单可见或接口存在推导完成率；真实服务验收与本轮模拟验证分开记录。

## 前后端交互契约

| 用户动作 | 前端责任 | 服务端责任与可见结果 |
| --- | --- | --- |
| 待办 / 最近项目打开对象 | URL 仅记录 screen、projectId 或 productId；刷新与前进 / 后退恢复对象 | 读取真实对象并校验工作空间 / 角色；商品详情独立于列表页，404 不改选第一页 |
| 商品列表选择 / 新建 / 保存 / 打开已有商品 | 同步详情选择、应用商品焦点与 URL；列表选择用 replaceState 避免堆积历史 | 列表与单项查询各自返回真实数据；延迟旧详情响应不得覆盖新的选择 |
| 01 资料 → 02 方案 | 展示商品版本与补充要求；AI 规划后用户保存 / 确认 | 规划受事实护栏约束；确认冻结商品 / SKU / 方案 / 价格快照，并执行乐观锁校验 |
| 03 编辑工作流 | 未开跑时编辑参数 / 布局 / 兼容连线，安全插入或删除改图节点；保存结束或明确丢弃后才能离开 | DAG、端口、锁定节点与 ETag 双重校验；冲突不覆盖本地草稿；确认与保存锁定同一实例并在提交时复核修订号；开跑后普通编辑锁定，手机与 viewer 只读，缩窄视口仍保留草稿和导航保护 |
| 03 估价 → 确认 → 运行 | 显示逐节点报价和待核价，用户明确确认；恢复页面只读取原运行 | 冻结图、一次预占、幂等提交；并发重放 / 冲突 / 部分预占失败只释放本次创建且未被胜出运行使用的预占；跨运行同键返回 409；失败停分支，unknown 保留预占并核实原任务，不自动换模型或重生 |
| 成功运行 → 04 | 刷新版本链与生命周期，展示新 draft | 免费输出节点幂等登记成功图片任务；登记失败只重试免费节点，不重新生成；draft 不自动成为候选 |
| 04 选候选 / 精修 | 用户显式选候选；精修先估价再确认；返修填写理由 | 保留版本链、单候选约束与不可变快照；精修只产 draft；撤销 / 返修退回 04 并保留历史 |
| 05 审核 | 对当前候选四项逐项保存，全部通过才能批准；撤销必填理由 | 按当前候选与审核 revision 校验；批准冻结版本，撤销解除候选 / 批准并保留追加记录 |
| 06 导出 | 展示就绪项与缺项；用户显式接受部分交付；读取历史与下载 ZIP | 只打包已批准候选，manifest 保存版本与缺项；零缺项且仍匹配当前候选的完成导出才完成第 06 步 |
| 生命周期 / 懒加载失败 | 显示过期或失败提示、只读重试 / 重载；保留全局导航 | 不伪造完成进度；慢响应不覆盖用户手动切换步骤；重试不得自动提交付费任务 |

项目详情、列表状态筛选与工作台共用服务端生命周期投影。前端不再以手动步骤事件判定真实项目完成；写请求仍由服务端逐接口鉴权并校验 CSRF、ETag 与幂等语义。

## 本轮交付

- 将六步进度投影到当前方案、工作流运行、交付候选、审核与导出真实记录，消除仅靠手动事件显示完成的差异。
- 输出节点成功后自动登记同一交付项的 draft 版本，按交付项状态行锁去重；导入失败可单独重试免费输出节点，不重复运行生图。
- 详情页在状态变化后刷新项目进度和新登记版本，按服务端当前步骤前进；失败和 unknown 不误报成功，draft 仍须显式选候选。
- 延迟的生命周期响应不覆盖用户手动切换的步骤；进度读取失败显示可能过期并允许只读重试。
- 懒加载页面失败时保留全局导航，并提供页面重新载入恢复入口。
- 懒加载五个主菜单的页面模块；项目页独立分包，减少首次进入工作台的加载体积。
- 未开跑工作流实例支持真实参数、布局、连线与安全改图节点编辑、另存模板；冲突保留草稿，导航保护未保存输入。
- 工作台直达代表项目 / 商品；商品跨页详情、404 重试、列表切换、新建与保存同步对象 URL，刷新恢复当前对象。
- 修复保存与确认竞态：两条写路径共用实例行锁，提交时复核图修订号；已保存新图时旧确认返回冲突并释放未使用预占。
- 修复窄屏切换导致的未保存草稿保护失效，以及素材索引延迟补齐导致同一成功任务重复登记版本。
- 修复并发确认、跨运行同键和部分预占失败的费用边界；统一预占补偿，保留胜出运行实际使用的共享预占。真实 SQL 验证同时发现并修复重复更新 updated_at 导致的 42601。
- 新增独立 PostgreSQL 集成测试入口，只能使用自建回环临时容器，不读取共享中间件连接配置。
- 验收覆盖状态投影、成功登记与显式候选门禁、慢响应竞态、生命周期刷新失败、懒加载失败、04/05/06 交付、工作台加载与移动布局。

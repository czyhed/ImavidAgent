# 创作改为项目无限画布，取消报价与强制审核

日期：2026-10-22。状态：用户确认，取代 ADR-0001 中的六步、锁定报价与审核节点。React/Node 选择继续遵循 ADR-0002。

## 决定

项目仍是正式创作入口，但以 React Flow 项目级无限画布为主。任务可多次生成，各次输入和结果独立保存。AI 只提出安排建议，用户确认修改并手动开始付费调用。报价方案与内部额度门槛删除，成功结果可立即使用。

## 取舍

保留旧 planVersion 作为核心会使追加任务、直接下载与多版本选择继续受方案冻结牵制。采用项目/任务/生成记录的归属模型，代价是重写活动创作界面与执行入口。用户确认旧数据均为测试数据，授权备份后清理，不做生产历史迁移。

## 不变的保护

商品事实和调用输入可追溯；未知不重新付费；AI 不自动执行；角色与工作空间隔离；被引用内容拒绝永久删除。完整决定见 requirements/creation-workbench-grilling.md。

# 2026-10-23 自由节点创作画布 v3：确认记录

状态：用户已确认全部问题（「按推荐执行」），视觉原型已验收（`prototype/canvas-v3.html`），v3 已实现、测试通过并部署。
本文件覆盖 v2（[creation-workbench-grilling.md](creation-workbench-grilling.md)）中被明确推翻的条目，
未提及的 v2 结论继续有效。

## 已确认决策

| 编号 | 主题 | 决定 |
| --- | --- | --- |
| V3-01 | 画布位置 | 不新增第六个菜单；项目即一张创作画布，工作台提供显眼的「新建画布」入口。 |
| V3-02 | 改造范围 | 视觉与交互重构 + 必要的数据模型扩展（多类型节点图、节点级任务、对话消息沿用），保留现有服务端执行与计费能力。 |
| V3-03 | 视觉基调 | 深色为默认、可切浅色；节点卡片参考 n8n；聊天体验参考 ChatGPT；强调色靛蓝 `#6366F1`；状态用语义色：排队灰、运行蓝、成功绿、失败红、等待输入琥珀；连线默认细灰、运行中流动高亮。 |
| V3-04 | 节点边界 | 节点类型限定在可执行集合内，组合自由；连线按数据类型校验。 |
| V3-05 | 审核 | 彻底移除人工审核与项目审核状态；节点全部成功即可导出/打包；项目只有运行态与回收站态。 |
| V3-06 | 进度 | 节点上显示状态徽标；项目底部常驻任务队列；工作台首屏显示跨项目运行中任务、待处理失败与最近项目。 |
| V3-07 | 重试 | 节点级一键重试，沿用原参数与原模型；重跑该节点及其下游，执行前明示可能费用；可展开改参数再试；不自动重试、不自动换模型。 |
| V3-08 | 商品聊天 | 本阶段做到「收集完成后可直接开始创作」；对话内改任务、看结果留到下一阶段（接口预留）。 |
| V3-09 | 商品到创作 | 点击「开始创作」后由 AI 直接生成初始画布（节点与连线排好），侧栏提供可勾选的任务清单，不需要先勾选再生成。 |
| V3-10 | 右侧面板 | 右侧改为紧凑属性面板，只放常用项（提示词、模型、尺寸、数量等），高级 JSON 折叠；生成历史移到底部任务队列。 |
| V3-11 | 节点语义 | 节点 = 可组合操作，不是单一生成任务；文本、图片可复用到多个下游。 |
| V3-12 | AI 规划入口 | 商品对话内与画布内都可触发 AI 规划；任何时候都能自由增删节点、改连线。 |
| V3-13 | 节点清单 | 一期提供：商品输入、图片输入、提示词（含 AI 扩写）、生图、改图、合成（模板 + 多图槽位）、视频（沿用 H3 执行器，界面注明未做真实付费验收）、输出（打包 ZIP）。 |
| V3-14 | 运行语义 | 手动运行选中节点，或「运行全部」按拓扑执行到输出节点；不自动级联。下游默认取上游「最新成功版本」，可在边上切换为指定版本；无成功版本时显示「等待输入」并禁止运行。**该条推翻 v2-Q25/q29 的「必须手选具体版本」。** |
| V3-15 | 任务队列 | 支持取消排队/运行中、单条重试、一键重试全部失败、状态筛选、点击定位节点、刷新恢复、显示耗时/模型/实际费用/错误原文。 |
| V3-16 | 费用 | 节点显示运行前预估（模型单价可知时）与运行后实际费用；不阻断执行；沿用按实际 usage 记账，无报价门禁。 |
| V3-17 | 撤销 | 支持撤销/重做（Ctrl+Z / Ctrl+Shift+Z）；不做图结构版本快照。 |
| V3-18 | 旧项目数据 | 清空旧项目、画布节点、连线、任务与运行记录、回收站；**保留**商品资料与聊天记录、素材库成功产出、提示词/参数模板、账号、渠道密钥、模型配置。部署时执行一次性清理，清理前 `pg_dump` 备份并写入部署记录；接受「回滚旧镜像也无法恢复旧项目、只能从备份库恢复」。 |
| V3-19 | 商品对话细节 | 支持文字、最多 8 张截图、1688 链接尽力解析（失败转文字追问，不阻断建档）；字段名称必填，价格/SKU/卖点/尺寸/材质/风格/目标场景可选；冲突仍走「采纳建议 / 保留原值」；ChatGPT 式气泡、流式输出、输入框自动增高、图片预览；顶部常驻「开始创作」，有名称即可点。 |
| V3-20 | AI 规划产物 | 直接生成初始画布（商品输入 → 提示词 → 若干生图/改图 → 输出）；点击前用小表单选张数、风格、是否改图分支；规划只用文本模型，不产生生图费用。 |
| V3-21 | 画布交互 | 双击空白或从节点面板拖入新建；节点悬停出「运行 / 更多」；Delete 删除、Ctrl+C/V 复制粘贴、Shift 多选、框选；小地图、缩放控件、适应视图；移动端只读查看 + 任务队列 + 重试，不做连线编辑。 |
| V3-22 | 旧代码 | 删除所有未挂载的 v1 组件与相关样式（ProjectPage、六步、WorkflowCanvas、GenerationStudio、旧 Products/Dashboard 等），在 Creation* 上改造。 |
| V3-23 | 交付节奏 | 先交付可点击的画布原型确认视觉方向，确认后再全量实现；原型不产生真实费用。 |

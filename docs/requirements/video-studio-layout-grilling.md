# 视频工作台界面重做（2026-10-27 确认）

建立在 [creation-sync-grilling.md](creation-sync-grilling.md) 的增量保存之上；分镜仍是画布 video 节点，生成方式、素材端口、配音、字幕规则沿用 [video-storyboard-v2-grilling.md](video-storyboard-v2-grilling.md)。用户要求直接开发，不先做静态原型。

## 现状问题

- 每个分镜是一张展开的长表单，8 个分镜要长距离滚动，看不到整片进度。
- 工作台里不能接素材，要切回画布连线。
- 右栏成片区多数时间是灰按钮，「说明」卡片是开发说明；左栏脚本与「商品事实」常驻占位。
- 看不到总时长和整片节奏，必须先拼接成片。

## 已确认决定

## 实现约定

- 顶部条：项目级参数、合计「N 镜 · 总时长 · 预估费用」（沿用现有批量预览的估算来源，不新增付费调用）、保存状态、「脚本」「角色与音色」「连播预览」「生成全部」「成片」。
- 单镜编辑区：左为方式切换（文字 / 首尾帧 / 全能参考，沿用 VideoNodeEditor 规则）、素材槽、提示词（`<Picture N>` 等标签可点击插入）、台词与配音（折叠）、参数（折叠）；右为本镜预览（版本切换、配音版 / 原声）与「生成本镜」「再生成一版」，仍走执行范围预览后再开始。
- 项目级参数随增量保存写入（storyboard 设置或等价字段，经 `storyboard.patch` / `project.patch`），生成时由服务端解析为分镜的有效参数；单镜覆盖存在节点 params。
- 不产生任何自动付费调用；生成、配音合成仍需用户点击并确认。

## 实现记录与偏离（2026-10-27）

以下是实现与上文约定的差异及原因；其余条目按原文实现。

- **保存状态不在工作台顶部条重复。** 约定里顶部条含「保存状态」，实际沿用画布页已有的顶部「已保存 / 未保存 / 保存中 / 保存失败·重试」（两个视图共用同一个保存队列）。在工作台再放一个同名状态节点只会重复，且让「已保存」类断言有两个命中。
- **合计里的预估费用只算尚未生成的分镜。** 「N 镜 · 总时长 · 预估费用」的费用取尚无成功版本的分镜，用批量预览同一套单价（`estimateVideoPoints`），不发请求；全部生成后显示「全部镜头已生成」。已有成功版本的分镜若再生成，预估在执行范围预览里给出。
- **项目级比例不含「跟随首帧」。** `adaptive` 取决于具体分镜是否有图片，只能在单镜「参数」里选，项目级只提供固定比例。
- **项目参数存「完整三项」。** 在顶部条改任何一项，都会写入 `{resolution, ratio, duration}` 全部三个键（未设置的用 V-04 默认 768P / 9:16 / 5 秒补齐），这样界面显示的值与服务端实际使用的值始终一致。同时清除分镜上与旧值或新值相同的显式参数（它们本来就不是真正的覆盖）；运行中的分镜不改（服务端禁止改执行输入），其显式值保留，若与新项目值不同会显示「自定义」。
- **新建分镜不再写死 768P / 9:16。** 项目有设置时，新建分镜（含 AI 分镜应用）只记录与项目时长不同的时长，分辨率与比例留空以跟随项目；没有设置时仍沿用原默认值，旧项目行为不变。
- **「自定义」的定义。** 节点显式参数与有效项目值不同才算自定义；显式值等于项目值不算。无项目设置的旧项目里，显式值与 V-04 默认值相同的分镜不显示「自定义」。
- **排序除拖动外保留「上移 / 下移」按钮。** HTML5 拖放在触屏上不可用，且现有无障碍与测试依赖这两个按钮，所以保留在单镜编辑区标题行。
- **「角色与音色」仍用原有的模态面板。** 约定写作侧边抽屉；该面板含音色库筛选、试听与音色设计，已有完整测试，本次只把入口移到顶部条，没有重做成抽屉。「脚本」「成片」是停靠在编辑区右侧的非模态抽屉（互斥，手机端占满宽度），不遮挡顶部条与时间线。
- **「生成全部」的可访问名称保留为「生成全部分镜」**，与既有批量预览测试和读屏一致；可见文字是「生成全部」。
- **失败分镜的「确认重试本镜」现在真正可开始。** 旧实现只传 `taskIds`，执行范围里该节点是「待确认重试」而不可开始；现在失败时同时传 `retryTaskIds`（与画布「重试」一致），仍先弹出执行范围预览，由用户点击「开始」才创建新请求。
- **「素材已删除」的判定依赖素材库列表加载完成**（`assetsLoaded`），列表返回里没有、已移入回收站或正在永久删除的素材算已删除；加载完成前不误报。尾帧素材已删除同样计入。提示词里指向已移除素材的标签也归入此类，文案区分为「提示词引用了已移除的素材」。
- **自动创建的输入节点带 `studioMade: true` 标记。** 只有带该标记、且不再被任何连线使用、且没有运行记录的节点，才会在移除素材时一并删除；用户在画布手动创建或 AI 应用生成的输入节点不会被工作台删除。
- **连播的占位镜头按真实时长计时**（该镜时长，最短 4 秒），不做加速。浏览器测试用替身 `play()` 让有视频的镜头立即结束，占位镜头走真实计时。
- **未在工作台提供「模型」下拉。** 单镜模型仍在画布节点里选（沿用环节默认）；约定的单镜编辑区没有要求它，本次不扩大范围。
- **任务队列改为可折叠，默认收起**，释放纵向空间；表格内容与列不变。

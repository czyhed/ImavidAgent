# 商境功能规格与开发基线 v2.0

更新：2026-10-22。用户经 Q01—Q43 确认，取代旧报价与六步审核生产线。需求已确认不等于已实现，实现与验证以 [STATUS.md](STATUS.md) 为准。逐项依据见 [完整 grill-me 记录](requirements/creation-workbench-grilling.md)；旧基线只读保留于 [archive/functional-spec-v1.1.md](archive/functional-spec-v1.1.md)。

## 1. 主流程

商品长期聊天整理事实 → 单独上传创作素材 → 创建项目直接进入 React Flow 无限画布 → 手动或 AI 安排 → 预览范围并开始 → 上游成功后手选具体结果 → 再开始下游 → 下载、修改或打包。

保留五菜单：工作台 / 项目 / 商品 / 素材 / 系统。报价、充值、余额预扣、强制候选/审核/导出门禁退出活动功能。

## 3. 一致性与存储约束

- 商品第一消息先保存；识别失败保留聊天附件。冲突及手工字段只提出建议，明确采纳才覆盖。
- 执行前冻结图修订、任务参数、商品快照、具体源版本和模型；同幂等键不重复调用。运行中不可改执行输入。
- AI 安排不执行；下游手选版本后固定，不跟随最新；无自动付费重试/模型回退。
- 素材删除不影响项目引用，永久删除拒绝引用；回收站恢复不自动生成。未知任务先核实终态再允许删项目。
- 私有桶只用 shangjing-assets / shangjing-exports。浏览器不持有长期凭据；Key 服务端加密，不进 URL/localStorage/日志。
- 供应商不默认信任私有 CA，视频首帧需可验证传输或公开 TLS 短时媒体网关。外链检查地址/跳转/体积。

## 4. 已确认测试接缝

商品会话与资料/图片用途接口；渠道/目录/能力/默认接口；项目画布/AI 建议/执行范围/启动/恢复/版本接口；素材/模板/回收站/永久删除接口；五菜单真实浏览器交互；PostgreSQL 持久化；模拟供应商 HTTP 协议。按公开接口验证，不把浏览器模拟当作真实供应商验收。

## 5. 2026-10-25 增补范围（用户以 final.png / caotu.png / B 版全功能图册确认）

| 编号 | 功能 | 交付行为 |

| FLOW-11 | 视频工作台 | 项目内独立「视频」页：AI 生成脚本与分镜（可编辑、可增删），逐镜文生 / 首帧可选，分镜即画布视频节点；AI 建议确认后才调用。 |
| FLOW-12 | 成片拼接 | 全部分镜成功后服务端 ffmpeg 按顺序拼接成片（静音、统一首镜尺寸），归集为结果素材可下载；不调用模型、无转场特效。 |

边界：音频环节按用户确认移除（成片无声，配音属后续 TTS 范围）；H3 视频仍无真实付费验收；成片拼接暂不纳入 ZIP 打包导出。
